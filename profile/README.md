<p>选线路这件事，最怕的不是选贵了，是选错了还不知道错在哪。有人按价格选，用两个月发现并发一上去就掉；有人按地区选，结果拿到的段归属对不上；还有人一次性买了一批，用到第三个月才发现没法退。这些问题本来都能在买之前问清楚。下面这份清单按四组展开，每组给出判断阈值和默认答案，照着走一遍，基本能排除大部分明显的坑。</p>

<h2>一、先答三个前置问题</h2>
<p>在打开任何供应商的报价页面之前，先把自己的三个数字写下来。没有这三个数字，后面的比较都是凭感觉。</p>
<table><thead><tr><th>前置问题</th><th>怎么算</th><th>常见取值</th></tr></thead><tbody><tr><td>峰值并发环境数</td><td>同时在线的最多环境，不是账号总数</td><td>三到五，或二十以上</td></tr><tr><td>需要几个地区</td><td>账号资料里出现过的国家/州省数量</td><td>一到两个，或五个以上</td></tr><tr><td>可接受月支出</td><td>按单个地址月费乘以数量估算</td><td>按实际预算定</td></tr></tbody></table>
<p>这三个数字决定了后面所有取舍。峰值三到五个环境的团队，不需要为千级池子付溢价；二十个以上并发的团队，省下来的那点单价通常会在排障时间上加倍还回去。</p>

<h2>二、第一组清单：规模与隔离级别</h2>
<p>隔离级别是这份清单里最容易被低估的一项。很多人以为买了独享地址就等于隔离了，其实地址只是其中一层，浏览器配置、时区、本地存储都算。</p>
<h3>隔离级别四选一</h3>
<p>第一级，共用地址加共用浏览器，只适合完全无关的测试号。第二级，独享地址加共用浏览器，地址分开了但环境没分，实际收益有限。第三级，独享地址加独立浏览器配置，多数业务的最低可接受线。第四级，独享地址加独立配置再加独立时区语言，多账号运营的常规选择。选级别的时候别看宣传语，看自己能不能把第三、第四层的配置真正执行下去。</p>
<h3>地址数量的估算公式</h3>
<p>经验公式是峰值并发环境数乘以三到五。留这个余量是因为换线、备用、临时扩容都要占地址。低于三倍时，一次故障就可能让几个环境抢同一条地址，前面的隔离白做。高于八倍则多半是浪费，除非有明确的地区覆盖需求。</p>

<h2>三、第二组清单：线路类型与地区覆盖</h2>
<p>线路类型的判断标准不是标签，是可核验的属性：ASN 归属、段类型、上游数量、路由表现。四项能查的尽量自己查一遍，别只看宣传页。</p>
<h3>原生家宽出口要看哪三项</h3>
<p>一看注册主体是不是当地运营商，二看 origin AS 是不是家宽 ASN，三看最后几跳是否落在接入网。三项一致才谈得上原生。只满足一项的，通常是机房段做了重新登记，用起来和机房段差别不大。</p>
<h3>地区覆盖按需买，不要贪多</h3>
<p>覆盖国家越多，单条地址的质量往往越难保证，因为供应商要在多个地区维持池子。业务只在一个州做，就买那个州的，多买的地区除了加价没有别的用处。要到新地区，按项目单独采购，别指望一套产品覆盖所有市场。</p>

<h2>四、第三组清单：成本与计费方式</h2>
<p>计费方式要和业务节奏匹配。长期稳定在线选按月，波动大选按小时，短期项目选按天。三种方式单价比起来差别明显，但总支出要看使用形态。</p>
<h3>三个容易被忽略的计费项</h3>
<p>一是流量超量费，二是并发超出后的降速或拒绝，三是停用期间是否继续计费。前两项在下单前问清楚，第三项在合同里写清楚。这三项加起来，有时候能占到总成本的两三成。</p>
<h3>价格区间怎么参考</h3>
<p>住宅静态地址按月的市场区间大致在每个几十元到一百多元，双 ISP、指定城市、独享段会更高；按小时计费折算下来通常略贵，但短期用总支出更低。这些数字仅供参考，实际以报价单为准。比较时统一折算成「每个环境每月」再比，别拿不同口径直接对比。</p>

<h2>五、第四组清单：运维能力与退出条件</h2>
<p>最后这组最容易被跳过，但它决定了出事时能不能快速止损。运维能力弱的团队，应该选管理后台简单、切换方便的产品，而不是参数最强但需要自己搭网关的方案。</p>
<h3>三项运维能力自评</h3>
<p>能不能自己写脚本查出口地址？能不能在十分钟内切换一条线路？有没有人负责看告警？三项都是「能」，可以选复杂方案；两项「不能」，优先选托管型；三项都「不能」，建议先从小批量开始，把流程跑通再放量。</p>
<h3>退出条件提前写</h3>
<p>什么情况下换供应商：连续两周漂移超过两次、核验通过率长期低于九成、工单响应超过二十四小时。把这些写下来，触发时按规则换，不用每次重新纠结。退出时确认三件事：账号绑定解除、日志导出、地址释放时间。</p>

<h2>常见问答</h2>
<h3>独享地址是不是就一定不会关联？</h3>
<p>答：不是。地址只是一层，浏览器配置、时区、登录节奏都会影响环境的一致性。独享地址解决的是出口层面的共用问题，其余几层还得自己配。</p>
<h3>小团队有必要买地区覆盖很广的产品吗？</h3>
<p>答：通常没有必要。覆盖越广，单条地址的质量越难稳定。按实际业务所在的地区买，集中在一两个地区，质量更容易保证。</p>
<h3>按月还是按小时更划算？</h3>
<p>答：看使用形态。每天在线超过十二小时、连续使用超过一个月，按月更省。使用时间零散或项目周期短，按小时更合适，关键是确认停用即停计费。</p>
<h3>什么时候该换供应商？</h3>
<p>答：建议提前定三条硬线：漂移频率、核验通过率、工单响应时间。任一持续不达标就换，不要因为「再试试」拖下去，拖的成本通常高于换的成本。</p>
